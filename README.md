# Technical Writer Portfolio

A static website for showcasing technical writing work — documentation samples, diagrams, and videos.

Live site: https://caroline03689.github.io/portfolio/

## Local Preview

```bash
cd portfolio
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## File Structure

```
portfolio/
├── index.html        # Main page
├── css/
│   └── style.css     # All styling
├── js/
│   └── main.js       # Interactions (nav, filter, modal, skills hover, contact popup)
├── images/           # Profile photo, doc screenshots, diagram SVGs/PNGs
├── videos/           # MP4 files and poster images
└── README.md         # This file
```
